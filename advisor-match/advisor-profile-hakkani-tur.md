## Research Focus
Conversational agents, large language models, task-oriented dialogue systems, LLM reasoning, evaluation frameworks, persuasion. Building open-source agentic LLMs (CoALM series).

## Key Publications (2025–2026)
- **CoALM** (2025): Unified Conversational Agentic Language Model — CoALM-405B is the largest fully open-source conversational agent LLM, ranked #1 on Berkeley Function Calling Leaderboard V3
- **ReIn** (ICLR 2026): Conversational error recovery with reasoning inception
- **ATOD** (2026): Evaluation framework and benchmark for agentic task-oriented dialogue
- **DialDefer** (2026): Detecting and mitigating LLM dialogic deference
- **Current Agents Fail to Leverage World Model as Tool for Foresight** (2026)
- **TT-SI** (ACL 2026): Self-Improving LLM Agents with Test-Time Training
