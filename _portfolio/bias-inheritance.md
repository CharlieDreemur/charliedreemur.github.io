This project studies how social bias in source data can be inherited and amplified through LLM-based data augmentation.

Key contributions include:

- Ran more than 50 controlled fine-tuning experiments using Llama 3.1 and ChatGPT o1-mini across different bias blend ratios.
- Built an automated pipeline for synthetic-data generation, bias injection, LoRA fine-tuning, and downstream evaluation.
- Evaluated mitigation strategies across classification and generation tasks.
- Contributed to the resulting ACL 2026 Oral paper.
