OpenManus-RL is a verl-based agent RL post-training framework and the follow-up project of OpenManus. I collaborated with the official OpenManus team as a core author in an open-source ecosystem with 62,000+ combined GitHub stars.

Key contributions include:

- Connected SFT, RL (PPO/GRPO), interactive environments, and trajectory rollout into one unified pipeline for training ReAct agents and tool use.
- Targeted long-horizon tasks such as GAIA, WebShop, and ALFWorld.
- Unified multi-turn environment interaction, tool actions, validation, and reward under a single ReAct trajectory protocol.
- Released a dataset of ~49K high-quality agent trajectories spanning OS, Web, Database, Knowledge Graph, Household, and E-commerce scenarios.
