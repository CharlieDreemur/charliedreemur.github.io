OpenManus-RL is a memory planning agent for general environments. The project implements a ReAct reasoning architecture and multi-agent flow for action optimization.

Key contributions include an MCP-compatible tool framework for automated tool invocation and output processing, plus SFT datasets compatible with AgentBench environments such as Gaia, WebArena, WebShop, and AlfWorld.
